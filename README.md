## 先搞懂：什么是CN2 GIA，为什么要认准它

CN2 GIA 是中国电信旗下的精品网络（CTG/CTGNet），路由识别特征是回程经过 `59.43.x.x` 的 IP 节点。简单说就是：**大陆访问国外服务器时走的"高速公路快车道"**，晚高峰优先保障，延迟和丢包率都比普通线路好一个档次。

普通 VPS 走的是 163 骨干网（4837），高峰期容易拥堵降速。CN2 GIA 走的是独立的优质通道，这就是贵的理由。

从实际使用来看，上海电信接美西 CN2 GIA 机房的延迟一般在 130–150ms，晚高峰丢包几乎可以忽略。这个表现，普通 VPS 想都别想。

**1. CN2 GIA 是不是只对电信用户有用？**

三网 CN2 GIA 对电信最友好，联通和移动用户也能走 CN2 GIA 回程，但去程路由不一定全走 CN2。如果你是移动用户，DMIT EB 系列和搬瓦工日本软银机房可能体验更好。

**3. 怎么验证 CN2 GIA 线路是真的？**

购买前，用商家提供的测试 IP 自己跑一下 `NextTrace` 或 `mtr`，回程路由里出现 `59.43.x.x` 就是电信 CN2，出现 `219.158.x.x` 是联通 4837，`10099.x.x` 是联通 9929。有些商家的 GIA 是"标榜"的，用工具跑完路由你自己看。

**4. 搬瓦工的优惠码还有用吗？**

根据各社区追踪，目前搬瓦工的常规优惠码有时候处于失效状态。建议在结算页面的 Promotional Code 栏试一下，有效就用，没有也不要纠结。搬瓦工通常一年有双十一（11%折扣）和黑五两次大促，那时候入手最划算。

**5. 这几家商家会跑路吗？**

搬瓦工母公司 IT7 Networks 成立于 2004 年，超过 20 年历史，跑路风险极低。DMIT 2018 年开始运营，口碑稳定，自有机房，跑路风险也相对可控。ZoroCloud 持有国内 IDC/ISP 许可证，另有一层保障。HostDare 2015 年成立，历史不短，但体量较小，建议年付不超过一年。
